# 共通仕様 v0.1

## 対象範囲
中学3科目、高校20科目（現代の国語・論理国語・数学I/A/II/B/III/C・生物基礎/生物・化学基礎/化学・物理基礎/物理・地学基礎/地学・地理総合/地理・歴史総合・情報I）、総合ポータル、フィードバック受付、管理者専用受信箱。情報IIは将来拡張候補。日本史探究・世界史探究は新規対象に含めない。

## 問題データ契約
```json
{
  "id": "subject-unit-0001",
  "subject": "highschool-information-1",
  "unit": "データ活用",
  "prompt": "オリジナルの問題文",
  "stimulus": [],
  "choices": [{"id":"A","text":"選択肢"}],
  "answer": ["A"],
  "explanation": "根拠を順に説明する",
  "difficulty": 1,
  "estimatedSeconds": 90,
  "sourceType": "original",
  "reviewed": false
}
```
- 多肢選択以外の科目に合わせて `answer` の形式はバージョン管理下で拡張する。
- 模擬問題と公式問題を明確に区別し、公式問題を無断転載しない。
- 問題を公開する前に、正答・誤答・解説・採点境界を人手または自動テストで確認する。

## フィードバック契約
必須: 本文のみ。任意: 種類、対象科目、優先度。氏名・メール・電話・住所・学校・SNS等は要求しない。入力欄の近くに「個人情報を書かずに送信してください」を表示。サーバーで長さ・型・許容値を検証し、レート制限とスパム対策を実装する。送信の成功は保存先から成功応答を受けたときだけ表示する。

## セキュリティ
- 管理画面とAPIの認証・認可をサーバー側で実施。デフォルト拒否。
- 公開クライアントに秘密鍵・管理者トークンを含めない。
- 一覧・詳細・更新・削除の全APIで毎回認可を検証。
- 出力時エスケープ、入力検証、CSRF/CORS設定、レート制限、監査ログ最小化。
- 管理者MFAが利用可能なら有効化。未認証APIテストを必須にする。
- 受信内容の保存期間、バックアップ、削除手順を公開前に決定。
- 静的サイト単独では秘密情報を持つ安全な受信バックエンドを構成できない。外部バックエンドが未設定なら送信済みと偽らない。

## UI
- キーボード操作、ラベル付きフォーム、フォーカス表示、読みやすいコントラスト、レスポンシブ対応。
- 最近使った科目・お気に入り・進捗は端末内保存を基本とし、保存場所を説明する。サイト間共有は明示的な設計なしに識別情報を収集しない。
