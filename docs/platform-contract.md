# 共通仕様 v0.3

## 対象範囲
中学3科目、高校21科目（現代の国語・論理国語・古典・数学I/A/II/B/III/C・生物基礎/生物・化学基礎/化学・物理基礎/物理・地学基礎/地学・地理総合/地理・歴史総合・情報I）、総合ポータル、フィードバック受付、管理者専用受信箱。情報IIは将来拡張候補。日本史探究・世界史探究は新規対象に含めない。

## リポジトリ構成
- 中学は国語・理科・社会の3リポジトリ。
- 高校理科は生物基礎・生物・化学基礎・化学・物理基礎・物理・地学基礎・地学の8科目を、それぞれ独立したリポジトリと学習サイトに分ける。
- 高校の国語・数学・社会・情報は教科別リポジトリ内で科目を選択する。
- ポータル上では理科を親カテゴリとして表示し、その下に8科目へのリンクを配置する。

## 法令・権利・プラットフォーム規約（必須）
- 日本国憲法を含む適用法令、条例、裁判所の命令、GitHub等の利用規約を守る。法的判断が必要な場合は断定せず、公開前に信頼できる一次情報や専門家による確認を求める。
- 教科書・市販教材・他サイト・画像・文章・図表・問題の著作権や利用条件を確認し、許諾のない複製・転載・再配布をしない。問題は原則オリジナルで作成し、引用は適法な範囲と要件を確認する。
- 個人情報は必要最小限にする。フォームで不要な氏名・連絡先・学校名等を要求しない。利用目的、保存先、保存期間、閲覧権限、削除方法を公開前に定める。
- 誤認させる表示、無断の追跡・情報収集、権限のないアクセス、セキュリティ制御の回避を実装しない。
- 法令適合性を完全に保証したと表示しない。疑義がある機能は公開を止め、確認・修正する。

## 問題データ契約
```json
{
  "id": "subject-unit-0001",
  "subject": "highschool-information-1",
  "unit": "データ活用",
  "prompt": "オリジナルの問題文",
  "stimulus": [],
  "choices": [{"id":"A","text":"選択肢"}],
  "answer": ["A"],
  "explanation": "根拠を順に説明する",
  "difficulty": 1,
  "estimatedSeconds": 90,
  "sourceType": "original",
  "reviewed": false
}
```
- 多肢選択以外の科目に合わせて `answer` の形式はバージョン管理下で拡張する。
- 模擬問題と公式問題を明確に区別し、公式問題を無断転載しない。
- 問題を公開する前に、正答・誤答・解説・採点境界を人手または自動テストで確認する。

## フィードバック契約
必須: 本文のみ。任意: 種類、対象科目、優先度。氏名・メール・電話・住所・学校・SNS等は要求しない。入力欄の近くに「個人情報を書かずに送信してください」を表示。サーバーで長さ・型・許容値を検証し、レート制限とスパム対策を実装する。送信の成功は保存先から成功応答を受けたときだけ表示する。

## セキュリティ
- 管理画面とAPIの認証・認可をサーバー側で実施。デフォルト拒否。
- 公開クライアントに秘密鍵・管理者トークンを含めない。
- 一覧・詳細・更新・削除の全APIで毎回認可を検証。
- 出力時エスケープ、入力検証、CSRF/CORS設定、レート制限、監査ログ最小化。
- 管理者MFAが利用可能なら有効化。未認証APIテストを必須にする。
- 受信内容の保存期間、バックアップ、削除手順を公開前に決定。
- 静的サイト単独では秘密情報を持つ安全な受信バックエンドを構成できない。外部バックエンドが未設定なら送信済みと偽らない。

## UI
- キーボード操作、ラベル付きフォーム、フォーカス表示、読みやすいコントラスト、レスポンシブ対応。
- 最近使った科目・お気に入り・進捗は端末内保存を基本とし、保存場所を説明する。サイト間共有は明示的な設計なしに識別情報を収集しない。
