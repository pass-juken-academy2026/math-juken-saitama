# 埼玉高校入試 数学トレーニング

中学数学の公式、条件付きの公式の使い方、裏技・時短テク、分野別演習、ミニ模試、間違い復習をまとめた学習サイトです。

## 公開サイト

- トップページ: https://pass-juken-academy2026.github.io/math-juken-saitama/
- 1〜12の直接リンク: `1.html` 〜 `12.html`（それぞれ該当単元へ移動）

## 学習内容

- 公式一覧：計算・展開、方程式、関数、図形、確率・データ
- 公式の直後に、使用条件・例外を添えた裏技／時短テク一覧
- 公式代入練習、一問一答、分野別演習
- 図形・証明、関数グラフ、文章題・規則性、確率・データ、図形の計量
- 入試形式演習、5問ミニ模試、間違い復習
- 125問のオリジナル問題バンク（分野別のランダム出題）
- 学習記録と復習待ちリスト（ブラウザのローカル保存が使える場合）

## GitHub Pages の公開設定

1. リポジトリの **Settings** を開く
2. 左メニューの **Pages** を選ぶ
3. **Build and deployment** の **Source** を「Deploy from a branch」にする
4. Branch を `main`、フォルダを `/(root)` にして **Save**
5. デプロイ完了後、上記の公開URLを開く
