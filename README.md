# 埼玉高校入試 数学トレーニング

中学数学の公式確認、分野別演習、ミニ模試、間違い復習をまとめた学習サイトです。

## 公開方法（GitHub Pages）

1. このリポジトリの **Settings** を開く
2. 左メニューの **Pages** を選ぶ
3. **Build and deployment** の **Source** を「Deploy from a branch」にする
4. Branch を `main`、フォルダを `/(root)` にして **Save**
5. しばらく待つと、次のURLで公開されます  
   https://pass-juken-academy2026.github.io/math-juken-saitama/

## 内容

- 公式一覧（分野で絞り込み）
- 公式代入練習
- 一問一答・分野選択演習
- 図形・証明、関数グラフ、文章題、確率・データ
- 入試形式オリジナル問題、5問ミニ模試
- 間違い復習リスト（同じブラウザ内に保存）

※掲載問題は学習用のオリジナル問題で、埼玉県の過去問そのものではありません。
